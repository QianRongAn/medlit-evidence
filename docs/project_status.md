## 当前状态

应用可运行：FastAPI + 静态仪表盘，支持 PubMed 检索、BM25 排序、规则 PICO、摘要整理、研究类型参考分级及完整性标记。已有训练数据、模型、SHAP 与探索性评估报告。

上一轮修复了已识别撤稿文献进入回答的问题，并补充参数限制、缓存复制、API 测试和 CI。

本轮审查发现最大缺陷是：将获益/伤害关键词当作对用户命题的支持/反对，随后生成冲突与高置信度。因此 0.2.0 删除这套自动判定，明确返回未评估状态，保留原始摘要与来源。

- `evidence.confidence`、`evidence.conflict` 改为 null，不代表 0 分或无冲突。
- 新增 assessment_version/status/note、unassessed_count；未评估不计作中立。
- 摘要句 polarity 为 unassessed；历史提问保留，旧判定标为停用。
- 页面和 README 不再承诺自动临床结论与置信度。
- 0.3.0：LLM 结构化输出逐条校验实际上下文中的 PMID 和原句，失败自动回退。展示每条对应原句；语义蕴含与临床适用性仍未验证。
- 0.3.0：撤稿模型输出改为 0–100 研究分数，明确未校准，删除百分比及风险等级。演示语料不评分，模型/标准化器均加载成功才报告就绪。
- 0.4.0：研究类型按明确发表类型优先，标题与自身方法描述保守补充，背景关键词不再抬高设计分级。
- 0.4.0：完整性状态保留关系方向、多项标记、通知身份与关联 PMID；通知不进入回答、LLM 或模型评分，修正后重发新版不继承旧版撤稿。84 项后端与 9 项前端回归通过。
- 0.5.0：搜索与回答共用 PICO/有效词项筛选，未纳入候选及原因单列；摘要与 LLM 引用原句检查所问结局。未知条件不放宽，离线先筛选后限量。112 项后端、10 项前端回归通过；词项筛选不等于临床语义适用性验证。
