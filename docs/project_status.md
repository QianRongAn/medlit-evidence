## 本轮推进

- 撤稿记录保留供查证，但从抽取回答、LLM 上下文与方向统计中排除。
- 无可用证据时置信度为 0，不再对零相关性文献做兜底结论。
- PubMed 成功返回空结果时保持在线空结果，仅请求失败才使用演示语料。
- 标注前复制缓存记录，避免请求修改共享的相关性及排序。
- 限制查询长度和返回数量；增加接口回归测试和 GitHub Actions。
- 前端区分 PubMed 抽取与演示抽取，区分零分与缺失评分，删除“可直接采信”提示。

## 下一阶段优先级

1. **对齐问题和结局，再判断方向。** 现有 `classify_polarity` 识别获益/伤害措辞，不能表达“是否支持用户提出的命题”。例如增加糖尿病风险与降低心血管事件涉及不同结局，不能直接作为证据互相冲突的证明。先建立带人群、干预、对照、结局和问句方向的人工标注集，再修改判定逻辑；在此之前应将现有方向视作文本规则标签。
2. **核查引文实验的评价指标。** `evaluate_citation_signal.py` 使用 PR 曲线梯形面积，未报告 average precision（AP）及测试集阳性比例。常量预测也可能因曲线端点产生较高的梯形面积；报告中“年份 AUC 0.500 / PR-AUC 0.578”需重新检查，不能据此认定年份模型更有区分力。补充常量基线、AP、阳性比例及置信区间。原始 `data/integrity_signals.jsonl` 被忽略、当前仓库未提供，不能宣称已复现实验。
3. **按预测时点截断信号。** 当前按发表年份切分不等同于前瞻预测未来撤稿；需明确撤稿日期、信号采集日期、观察窗口与删失处理。作者/期刊历史及引文关系只能使用预测时点之前的信息。
4. **验证 LLM 引用。** 本轮保证输入上下文排除已撤稿文献，尚未验证模型输出的每个 PMID 都来自上下文，也未验证每项陈述与原文的蕴含关系。增加引用白名单检查及失败回退。
5. **再接多信号关系数据。** 在以上评价协议就绪后推进作者历史、引文图和关联解释，避免以增加采集规模替代验证。

## 验证范围

接口测试通过替身验证 PubMed 空结果、网络故障、无匹配、全部撤稿、混合证据、LLM 成功/失败、输入限制及缓存隔离。不以在线检索结果或临床正确性作为本轮通过依据；未重新训练或复现引文实验。
