# 检索与 PICO 筛选（0.5.0）

## 从候选到回答

PubMed 召回提供候选，BM25 用去重后的词典变体和有效查询词排序；BM25>0 本身不再意味着可以进入回答。

`build_query_plan` 保留 PICO 词项及其他有效英文词项。明确识别的 P/I/C/O 条件全部参与本地筛选；其余有效词项也须全部命中，以免在未知角色时任意丢掉一个药名或结局。没有识别到的字段不自动加条件。

- P/I/C 使用标题和摘要；O 必须在摘要出现，不能只用标题冒充研究结果。
- 英文词项按词边界匹配；中文词典优先较长概念。普通糖尿病不擅自指定类型，typed diabetes 和特定癌种不重复计泛词。
- 新发/风险疾病结局不作为已有该病的人群；疾病作结局时还检查邻近的发病、风险、预防等词项线索，不能只拿“患该病的人群”满足结局。
- 比较标记后的已知药物归入 C，具体药物保持自身名称，不因共属一类而把比较双方合并。placebo、standard care 等可直接作为对照词项。
- 对 P/C 的简单否定线索不计为正向覆盖。无法处理的排除查询、数字阈值、时窗、“或者”和未映射中文条件会标为 unsupported_query，不默默放宽。
- 缺少摘要的文献保留到未纳入列表，不生成回答。缺少标题但摘要覆盖条件的记录仍可通过。
- 撤稿和通知沿用完整性过滤；它们可以词项通过并保留供核查，但不会作为回答来源。

抽取式回答在已通过的文献中选择与所问结局匹配的句子；不能用药名重复出现的其他结局句子抢占答案。若只有词典外有效词项，也不丢掉这些词项。LLM 的引用原句通过同样检查，真实但离题的原句也会导致整体回退。

## 接口与页面

`/api/search` 与 `/api/answer` 共用 `_screened_retrieval`。结果包含：

| 字段 | 含义 |
| --- | --- |
| total | PubMed 原始命中总数；离线时为本地有排序命中的候选数 |
| results | 通过本地词项条件、按 retmax 截断的记录 |
| excluded_results | 当前取得的候选中未通过筛选的记录和原因，不进入回答、等级分布或证据统计 |
| screening.candidate_count | 实际筛选的候选数，不是 PubMed 全库总数 |
| screening.matched_count / included_count | 词项命中数 / 按 retmax 展示的命中数 |
| screening.excluded_count | 未通过词项筛选的候选数 |
| screening.status | matched、no_match 或 unsupported_query；matched 不保证有完整性允许的研究或可摘录句子 |
| screening.pico_constraints | 本次实际使用的 PICO 词项条件，与页面展示一致 |
| screening.lexical_terms / unmapped_terms / issues | 其余有效词、未映射中文、不能可靠解析的条件 |
| 单篇 screening | eligible、reasons、各字段 required/matched/missing、词项覆盖率 |
| answer_eligible | 词项通过且完整性允许，可作为回答候选；不等于已验证临床适用 |
| relevance / bm25_score | 词项覆盖百分比 / 未按候选最高值归一化的原始 BM25 排序分 |

页面区分纳入来源和折叠的“未纳入候选”。排除原因与完整性标记、关联记录保留可查；不将词项缺失解释为研究被证实临床不适用。

离线语料先检查所有有排序命中的记录，再按返回上限截断。在线只筛当前 PubMed 返回的最多 retmax 篇，不声称已筛完全部命中文献，也不会在无结果时使用演示语料替代。

## 边界与回归

这是保守的词典/文本规则，并非向量语义检索、完整 PICO 标注或临床适用性验证。未覆盖的同义表达、药物类属、句间指代、复杂否定与研究分组会导致漏召回或仍需人工核查。暂未用独立临床标注集估计 precision/recall；后续应在固定查询集上评估再扩展词典，不能通过随意降低条件覆盖要求换取有答案。

回归覆盖中英文等价查询、混合字母数字中文、未知英文药名不能丢弃、药名边界、不同糖尿病类型、成人/儿童、活性比较药物、结局缺失、缺摘要、无结果、未知条件弃权、实际 LLM 离题引用回退、缓存隔离，以及离线先筛选后限量。
