# P1 修复与已知基准复测

日期：2026-10-18；应用版本0.6.0。**本轮使用已公开且已据此开发的30题基准，是开发复测，不是新的独立验证。标注及逐句复核仍由开发者模型完成，临床专家复核待完成。**

## 修改

- 翻译与PICO共用医学词表，新增六种干预和活性对照、肥胖/OSA/COPD/早期AD等人群，以及减重、AHI、加重、认知下降、严重出血结局；别名最长匹配，英文保持词边界。
- 中文普通问句中的“有何”“怎么样”等作为完整语气短语处理，保留未知疾病、人群、排除条件与数字约束的弃权机制。
- 抽取按整节保留章节身份，背景、方法、研究目的和终点定义不作为结果输出；结果和结论中的否定与不确定性保留。新加 `source_section` 供追溯。
- 分句保留vs./et al./e.g.等缩写及原始数字比较，不改写原文。
- LLM上下文优先取完整结论/结果句，预算不足跳过整句，不能截断比较；实际引用必须是发送上下文中的完整可用句。原句和来源校验仍不等于LLM语义蕴含验证。

## 剩余问题

- Q07/Q08能找到FINEARTS-HF，但摘要的结果主要给恶化心衰复合事件而无单独住院结果；没有用方法中的终点定义冒充住院获益，继续无回答。
- 人群词在背景或结局中出现仍可能被误当作入组人群。严格PICO需要进一步做研究自身人群、对照和结局的角色定位。
- 非结构化摘要可能引述既往结果；目前章节过滤不等于理解所有背景语句。
- 基线数值仍可能进入结果摘录，部分输出不直接回答问题；62句中只有48句被本次模型审核为直接回应。
- 生存显著性阈值、复合与单独结局等仍需人工复核，不恢复自动临床结论。
- 真实LLM调用0，本轮只通过模拟HTTP验证了上下文和引用防线，实际生成忠实率仍不可评估。下一轮需要新的未见问题和独立临床评审，不能继续把本开发集称为独立正确率。
