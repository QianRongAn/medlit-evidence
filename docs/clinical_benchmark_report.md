# 独立来源临床评测：第一版初评

日期：2026-10-18。**这是开发者模型依据原始摘要完成的标注初评，未经临床专家盲审；不是专家金标准，也不是整体临床正确率。**

30个新问题（15组中英文表达）、12篇真实PubMed报告、360项完整问题—文献判定。来源覆盖10个试验家族，有24个候选池内可回答问题、6个池内无直接证据问题。文献PMID与两份训练表无重叠，问题未复用已有回归测试文本。标签在首次运行前单独提交冻结为 `111dc66`；运行应用代码与 `d784caf` 相同。不是针对临床真实流量的随机抽样，无法排除语言模型预训练中见过这些文献。

评测实际执行ASGI搜索及回答接口，固定离线文献池，运行BM25、PICO、筛选和抽取器；只替换外部PubMed取数和不相关的风险评分。候选池不是完整PubMed；不测在线召回、网络可用性或排序服务。每题最多返回5篇，未返回的槽位不算正确，另报告覆盖率。

忠实率23/26由逐句阅读摘要全文及语境判定，未使用“原句存在即忠实”的判法。未输出的答案不进入忠实率分母，因此必须同时看覆盖率。两种语言可能返回同一句话，26项不是26个独立样本；12篇报告也有同试验的关联报告。不提供伪精确的总体置信区间。

本轮是默认抽取模式，真实LLM成功调用为0，**生成式LLM摘要忠实率仍为不可评估**。不能把抽取模式的88.5%用于宣传LLM准确率。评测器可用 `--mode llm` 单独执行，必须配置凭证；报告按真实返回模式分组，回退结果不会冒充LLM结果。

## 发现的问题及优先级

1. **P1：中文覆盖不足。** 新药、疾病、结局词典缺口导致放弃查询；Q18即使PICO四项解析完整，也因普通问法中的“何”被当作未知条件而弃答。需要完整中文问句解析与术语映射，不能只扩药名字典。
2. **P1：抽取丢失背景时间语境。** Q01和Q17把研究前“尚不清楚”的背景句与已有最终结果并列，构成误导，忠实判定为失败。
3. **P1：分句破坏数值比较。** Q21在 `vs.` 处截断，缺失对照数值和区间，按不完整陈述判失败。
4. **P2：出现所问结局不代表PICO一致。** Q15同时选入DAPA-CKD和DAPA-HF，前者的人群不是所问的心衰入组人群。
5. **P2：单句必须覆盖全部检索词造成无回答。** Q03/Q05/Q07/Q11能找到相关文献却没有摘录；干预名常在方法句，结果句用组别或代词指代。不能用放松人群和结局约束来解决。

本轮没有修改应用规则来抬高分数。该基准结果已被开发者看到，后续可用于比较修复；下一次真正未见的检验应另采样并由独立人员复核。

## 可复现与复核

数据、标注和逐句理由见 [clinical_v1](../evaluation/clinical_v1/)。标注文件带模型作者和 `expert_review_status=pending`，不得改名为临床专家标注。运行及复核方法见 [评测协议](clinical_benchmark_protocol.md)。

`manifest.json`冻结来源、标签文件哈希；`baseline_run.json`保留应用/评测器哈希、返回来源、PICO、筛选原因及原句；`baseline_run.review.json`保留26项逐句判定和理由；`baseline_run.metrics.json`保存全部分子/分母与语言/模式分组。

已提供不含初稿答案的三份CSV盲审表，供临床人员独立标注。人工评审尚未发生，复核后应保留初版、另建专家复核版本并记录分歧与裁决。

验证：151项Python测试、10项Node前端测试通过。新增15项评测协议回归覆盖空分母、弃答、错误人群、未审核/过期判定、数据篡改、分模式统计和实际ASGI链路。
